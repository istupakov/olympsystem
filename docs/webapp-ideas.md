# WebApp ideas

Remaining work and ideas for future discussion. Access decisions are maintained in
[access-control.md](access-control.md).

## Remaining migration

- Contest materials: import problems from ZIP, upload/remove statements PDF,
  generate test archives, and rejudge submissions.
- Jury standings without freeze restrictions and submission search across contests.
- Runner monitoring, compiler versions and self-test results, manual code execution,
  and administrator controls for compiler availability.
- Jury replies, announcements, and problem clarifications, replacing QReply.
- Runner RPC with API-key authentication and production hosting: health checks,
  persistent Data Protection keys, certificates, and Compose deployment.

## Future ideas

- Progress across contests, including coach views, with personal practice and team
  participation shown separately. Apply the existing result visibility rules.
- Problem statistics: solvers, submissions, and acceptance rates, separating contest
  attempts from later practice.
- Source drafts and compiler selection retained per account and problem within a
  browser tab; clear the draft after successful submission.
- Standalone problems, problem topics, and progress grouped by topic.
- Choosing a coach in the user profile.
