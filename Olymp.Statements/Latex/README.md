# olymp.sty

[olymp.sty](./olymp.sty) is an unmodified copy from
[GassaFM/olymp.sty](https://github.com/GassaFM/olymp.sty/blob/b4858d1f05efbca9d0723d6524aad6319d09d7ca/statements/olymp.sty),
commit `b4858d1f05efbca9d0723d6524aad6319d09d7ca`. Its license is included in
[LICENSE](./LICENSE).

The style, license and [preamble](./preamble.tex) are embedded in Olymp.Statements.
The preamble configures Russian UTF-8 statements for pdfLaTeX. The TeX export
includes the style and license and uses the preamble to build the main document.
